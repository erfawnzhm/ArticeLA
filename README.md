## 🚀 اسکیل ArticeLA نسخه ۲ - مقاله‌ساز هوشمند فناوری اطلاعات

این اسکیل برای تولید مقالات تخصصی، ساختاریافته و باکیفیت در حوزه فناوری اطلاعات (IT) و شبکه‌های کامپیوتری به زبان فارسی طراحی شده است.

### ✨ ویژگی‌های این نسخه:
- **دقت فنی بالا:** بهینه‌سازی شده برای مفاهیم تخصصی شبکه، زیرساخت و فناوری اطلاعات.
- **ساختار استاندارد و سئو شده:** رعایت اصول نگارشی، تیتربندی منظم و لحن روان فارسی.
- **قالب‌های آماده:** شامل دستورالعمل‌های دقیق برای تولید محتوای آموزشی و تخصصی.

### 📦 نحوه نصب و استفاده:
1. فایل `articela-v2.zip` را از بخش **Assets** در پایین همین صفحه دانلود کنید.
2. فایل زیپ را در محیط هوش مصنوعی خود ایمپورت (Import) کنید.
3. برای نگارش مقالات تخصصی IT، اسکیل را فراخوانی کنید.
